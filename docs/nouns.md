# Nouns

Temory has three nouns: **people**, **activities**, and **places**. Each one links to every other, both ways.

What each noun's page shows about the others:

| Page         | People             | Activities           | Places             |
| ------------ | ------------------ | -------------------- | ------------------ |
| **Person**   | —                  | what you do together | where you see them |
| **Activity** | who you do it with | —                    | where you do it    |
| **Place**    | who goes there     | what you do there    | —                  |

- A link is one join table, shown and editable from both sides.
- Moments in the journal can mention any noun.
- A new noun (a new tab) links to every existing one, with a section for each on both pages.
